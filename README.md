# Режиссёрское портфолио — статичный сайт

Одностраничник: hero с шоурилом → таблица работ → о себе → контакты.
Два языка (EN / PL), тёмная палитра, моно-подписи, плёночное зерно.

**Без сборки и зависимостей.** Это чистые HTML + CSS + JS. Vercel раздаёт папку как есть,
деплой занимает секунды, ломаться нечему.

---

## 1. Посмотреть локально

Просто открой `index.html` двойным кликом — почти всё заработает.
Чтобы работало абсолютно всё (и не ругался браузер), лучше поднять локальный сервер:

```bash
cd director-portfolio
python3 -m http.server 8000
# открой http://localhost:8000
```

Полезно: `http://localhost:8000/?lang=pl` — сразу польская версия.
`?noanim=1` — выключить анимации (удобно для скриншотов).

## 2. Где менять контент

**Весь текст, все проекты, все ссылки — в одном файле: `content.js`.**
Больше ничего трогать не нужно.

### Имя, город, контакты — блок `SITE`

```js
name: "RUSTAM BULATOV",       // имя в шапке и подвале
city: { en: "Warsaw", pl: "Warszawa" },
email: "rustambulatov05@gmail.com",
socials: [ { label: "Instagram", url: "https://instagram.com/" } ],
```

### Шоурил на первом экране

```js
reel: {
  year: "2026",                  // подпись SHOWREEL 2026
  poster: "assets/img/hero.jpg", // кадр 12:5, который видно, пока видео грузится
  autoplay: true,                // сам стартует, без звука, по кругу
  video: { kind: "drive", id: "1IxMo…" },
},
```

Шоурил запускается сам, как только открыли сайт: без звука и по кругу.
Клик по кадру открывает большое окно — там уже со звуком и перемоткой.
Звук без клика включить нельзя: браузеры разрешают автозапуск только беззвучный.
`autoplay: false` — вернуть старое поведение (постер и кнопка PLAY).
При системной настройке «уменьшить движение» автозапуска не будет.

Убери `video` — блок шоурила пропадёт целиком.

**Три варианта источника:**

| `kind` | что писать | автозапуск |
|---|---|---|
| `"mp4"` | `{ kind: "mp4", src: "assets/video/reel.mp4" }` | всегда — самый надёжный |
| `"drive"` | `{ kind: "drive", id: "ID_ИЗ_ССЫЛКИ" }` | обычно да, см. ниже |
| `"youtube"` | `{ kind: "youtube", id: "ID_ИЗ_ССЫЛКИ" }` | всегда |

**Как взять ID с Google Drive:** из `https://drive.google.com/file/d/`**`1IxMo…`**`/view`
берём то, что между `/d/` и `/view`. Файл должен быть открыт по ссылке
(«Доступ» → «Все, у кого есть ссылка»), иначе на сайте он не покажется.

Drive отдаёт файл потоком — сайт берёт его напрямую и крутит как обычное видео.
Если Drive потоком не отдал (так бывает с очень тяжёлыми файлами), сайт сам
переключается на встроенный плеер Drive; он показывает кадр, но стартовать
может попросить нажатием. Нужен гарантированный автозапуск — положи mp4
в `assets/video/reel.mp4` и поставь `kind: "mp4"`.

**Как взять ID с YouTube:** из `https://www.youtube.com/watch?v=`**`dQw4w9WgXcQ`** берём то,
что после `v=`. Из короткой ссылки `https://youtu.be/`**`dQw4w9WgXcQ`** — то, что после слэша.

### Работы — массив `PROJECTS`

Один блок `{ ... }` = одна карточка. Копируй, удаляй, меняй местами — порядок на сайте
такой же, как в файле.

```js
{
  title: "Metropolis",
  year: "2025",
  format: { en: "Commercial · 60″", pl: "Reklama · 60″" }, // колонка FORMAT
  poster: "assets/img/work-1.jpg",      // кадр из работы
  video: { kind: "youtube", id: "..." },// или { kind: "mp4", src: "..." }, или null
  description: { en: "...", pl: "..." },
  credits: [ { k: { en: "DOP", pl: "Operator" }, v: "Имя" } ],
}
```

Каждый блок — одна строка в таблице. Строка раскрывается по клику: кадр, титры,
описание и кнопка WATCH, которая открывает видео.
Порядок в таблице — по году; кнопка **BY YEAR** переключает направление.

### О себе — объект `ABOUT`

```js
statement: { en: ["абзац", "абзац"], pl: [...] },       // текст слева
meta: [ { k: { en: "Based", ... }, v: { en: "Warsaw", ... } } ],  // строки справа
```

### Тексты интерфейса — объект `I18N`

Все надписи (кнопки, заголовки секций, подписи) — там, отдельно для `en` и `pl`.
Меняешь строку — меняется на сайте.

## 3. Картинки

Положи свои файлы в `assets/img/` с теми же именами — они подхватятся сами.
Сейчас там временные заглушки (тёмно-синие градиенты с подписью «PLACEHOLDER»).

| Файл | Размер | Что это |
|---|---|---|
| `hero.jpg` | 2400×1000 | кадр-заставка шоурила (виден, пока грузится видео) |
| `work-1…6.jpg` | 1600×900 | кадры работ в раскрытых строках (сейчас в `content.js` вместо них превью с YouTube) |
| `og.jpg` | 1200×630 | превью при отправке ссылки в мессенджер |
| `portrait.jpg` | вертикальный | портрет в секции ABOUT и фото для поисковиков |

Держи каждый файл до ~500 КБ, иначе сайт будет грузиться медленно.
Быстро сжать: [squoosh.app](https://squoosh.app) → формат JPEG/WebP, качество 75–80.

Видеофайлы (если выберешь mp4) клади в `assets/video/`. Держи их до 10 МБ:
Vercel отдаёт большие файлы медленно, и мобильный интернет их не вывезет.
Для полных работ лучше YouTube — он сам подберёт качество под связь зрителя.

Хочешь сгенерировать заглушки заново — `python3 tools/make_placeholders.py`
(нужны `pillow` и `numpy`). Папку `tools/` можно удалить, на сайт она не влияет.

## 3.1. Превью ссылки и поисковики

Когда ссылку на сайт кидают в Telegram, WhatsApp, Facebook или Slack,
подтягивается `assets/img/og.jpg` — 1200×630, портрет слева, имя справа.
Он же лежит в `<meta property="og:image">` в `index.html`.

Портрет `assets/img/portrait.jpg` показывается в секции ABOUT и отдаётся
поисковикам как фото человека — через блок `application/ld+json` в `<head>`
(разметка `Person`: имя, роль, город, языки, почта). Благодаря
`max-image-preview:large` Google может показать его крупно в выдаче.

### Впиши домен, когда он появится

В `content.js`, блок `SITE`:

```js
url: "https://rustambulatov.com",   // без слэша на конце
```

Пока строка пустая, пути к картинке относительные. Telegram, Facebook, Slack
и Discord достраивают их сами, а LinkedIn, X и часть ботов — нет. С доменом
`app.js` подставит абсолютные адреса везде: `og:image`, `twitter:image`,
`canonical`, `og:url` и в структурированных данных.

Проверить превью после деплоя:

* Facebook — [developers.facebook.com/tools/debug](https://developers.facebook.com/tools/debug/)
* X — [cards-dev.twitter.com/validator](https://cards-dev.twitter.com/validator)
* Разметка для Google — [search.google.com/test/rich-results](https://search.google.com/test/rich-results)

Соцсети кешируют превью. Поменял `og.jpg` — прогони ссылку через отладчик
Facebook и нажми **Scrape Again**, иначе старая картинка провисит сутки.

## 4. Выложить на GitHub

### Вариант А — без командной строки (проще)

1. Заходишь на [github.com](https://github.com) → **New repository**
2. Имя, например `portfolio`, **Public**, ничего больше не отмечаешь → **Create repository**
3. На странице репозитория → **uploading an existing file**
4. Перетаскиваешь **содержимое** папки `director-portfolio` (не саму папку — то, что внутри:
   `index.html`, `styles.css`, `app.js`, `content.js`, `vercel.json`, папку `assets`)
5. **Commit changes**

### Вариант Б — через терминал

```bash
cd director-portfolio
git init
git add .
git commit -m "Portfolio site"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/portfolio.git
git push -u origin main
```

## 5. Подключить Vercel

1. [vercel.com](https://vercel.com) → **Sign up** → **Continue with GitHub**
2. **Add New…** → **Project**
3. Находишь репозиторий `portfolio` → **Import**
4. **Framework Preset: Other.** Build Command и Output Directory оставь **пустыми** —
   сборка не нужна, это статика
5. **Deploy**

Через ~20 секунд получишь адрес вида `portfolio-xxx.vercel.app`.

**Свой домен:** проект → **Settings** → **Domains** → **Add** → вводишь домен и
прописываешь у регистратора DNS-записи, которые покажет Vercel.

---

## 6. Как обновлять сайт дальше

Любое изменение в GitHub автоматически пересобирает и выкатывает сайт — руками ничего делать
не надо.

- **Мелкая правка** (текст, ссылка, новый проект): открываешь `content.js` прямо на GitHub →
  карандаш → правишь → **Commit changes**. Через полминуты изменения на сайте.
- **Новые фото:** репозиторий → папка `assets/img` → **Add file** → **Upload files**.
- **Через Claude Code / Cowork:** клонируешь репозиторий себе, открываешь папку и просишь
  словами — «добавь работу такую-то», «поменяй акцентный цвет». Потом `git push`.

## 7. Настройки внешнего вида

Вся палитра — в начале `styles.css`, блок `:root`:

```css
--bg:    #080d13;   /* основной фон */
--ink:   #e9eef2;   /* основной текст */
--ink-2: #aebac4;   /* вторичный текст */
--muted: #61717e;   /* моно-подписи */
--line:  rgba(233, 238, 242, .10);  /* линейки таблицы */
```

Сила зерна — там же, селектор `.grain`, свойство `opacity` (сейчас `.035`).
Убрать зерно совсем — поставить `opacity: 0`.

## Структура

```

content.js    ← твой контент, только его и правишь

assets/img/   картинки
assets/video/ видеофайлы (если mp4)
tools/        генератор заглушек, для сайта не нужен
```
